# @cristal/tokens

Design tokens of the [Cristal](https://lucaslle.github.io/Cristal-UI/) design system as CSS custom properties.

```js
import '@cristal/tokens/tokens.css';
import '@cristal/tokens/tokens-dark.css'; // optional, applied with data-theme="dark"
```

One line sets your brand colour; hover, subtle, text and focus shades are derived from it:

```css
:root {
  --cr-color-primary: #e11d48;
}
```
