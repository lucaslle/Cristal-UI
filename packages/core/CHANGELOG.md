# @cristal/core

## 0.1.0

### Minor Changes

- a3aaf6a: Add cr-accordion and cr-accordion-item following the W3C accordion pattern: single or multiple open sections, "Tout ouvrir / Tout fermer" with staggered opening, side-by-side panels variant, numbered headers, and slide, accent-bar and cascade (staggered lines, count-up numbers, growing bars) animations, all reduced to no motion when requested.
- f4648c1: Built-in texts (validation messages, stepper buttons, table and grid layout announcements, close labels, search and card captions) now come in English and French. English is the default; French is used when the component or an ancestor has lang="fr". closeLabel (cr-dialog, cr-drawer) and label (cr-stepper, cr-grid-layout) no longer default to French text: when unset they use the translated default.
- 7b9d0e4: Add cr-avatar and cr-avatar-group. cr-avatar shows a photo, or initials on a colour derived from the name (hue shifts of the primary colour, white text kept at 4.5:1 or more) when there is no photo or it fails to load; it is an image named by the person, with an optional status (online, away, busy, offline) added to the name and shown by a badge whose shape changes with the status. The online badge pulses three times then stops. cr-avatar-group overlaps its avatars, fans them out on hover or focus, and sums up those beyond max with a "+N" named "N more people".
- c50d2d4: Add cr-alert and cr-toaster: a message with info, success, warning and danger variants, an optional heading, and a crClose event on every close; where it is placed decides how it behaves. In the page it is an inline banner: it unfolds in height when inserted after page load, and an optional Close button folds it away. Inside a cr-toaster (a fixed area at the bottom right that stacks messages) it is a toast: it slides in from the corner, closes after duration (5000 ms by default, 0 to keep it) with a remaining-time bar that pauses on hover and focus, and closes with its Close button, Escape or a sideways swipe. In both places the message is a status region (an alert region for danger), its type is shown by a distinct icon that draws itself and a prefix read by screen readers ("Error: "), not by colour alone, and the text never fades in; motion is removed when less motion is requested.
- 908064c: Add cr-theme-toggle (React CrThemeToggle): a round button whose sun morphs into a moon (rays tuck in, a disc slides over to carve the crescent). A click sets data-theme on <html> and emits crChange with the new theme; the initial theme comes from data-theme, otherwise prefers-color-scheme, and later changes of data-theme made elsewhere are followed. transition animates the whole page with the View Transitions API: circle (default, from the button), curtain, blinds, flip, eclipse, sweep or none; the switch is instant where the API is missing or when less motion is requested. It is a real button with aria-pressed and a translated name ("Dark theme" / "Thème sombre"), a 40 px target, a visible focus, a 3:1 icon in both themes and system colours in forced colours. Keeping the choice is left to the application.

  variant chooses the shape: icon (round button, default), switch (a real switch whose thumb slides carrying the icon, over a light day track with a sun glow or a dark night track with stars; role="switch" with aria-checked) or label (a pill with the icon and the visible "Dark theme" / "Thème sombre" text, which is the whole accessible name). icon chooses the icon animation in all three variants: morph (default), rotate (the sun spins out as the moon spins in), rise (the sun sets below a horizon, the moon rises), flip (a 3D coin flip) or eclipse (a disc slides across the sun, its rays turn into stars). No icon animation and no thumb slide when less motion is requested; the page transition starts from the switch thumb.

- 67ca3c9: Add cr-icon-button: icon-only button named by a required label shown as a tooltip on hover and keyboard focus (Escape hides it), ghost/primary/secondary/outline variants, square or round shape, xs to l sizes, toggle mode with aria-pressed and crToggle, badge added to the accessible name, loading and disabled states.
- 66829f4: cr-button and cr-icon-button gain href and target: with href they render a real link, so Ctrl/Cmd+click, middle click and "Open in new tab" are native. A disabled or loading link loses its href; target="_blank" adds rel="noopener noreferrer".
- 5411fe5: Add cr-radio-group, a form-associated radio group following the W3C pattern (visible title, single Tab stop, arrow keys that wrap and skip disabled options, required validation): the dot flows from the old circle to the new one, and simply appears when less motion is requested.
- 3714bf3: Add cr-otp (one-time code boxes with a completion wave), cr-card-input (grouped card number, Luhn check, sliding expiry and CVC, optional realistic card preview with network colours, chip, embossed digits, magnetic stripe and flip for the CVC, optional cardholder field, and variant="card" to type everything directly on the drawn card), cr-textarea (grows a line at a time), cr-tag-input (removable chips) and cr-box (layout div replacement with theme spacing). cr-input gains a password strength meter and inline ghost completion. Fix element methods shadowed by private fields in cr-table (before), cr-stepper (focus) and cr-menu (focus).
- 8d359ef: Add loading components: cr-skeleton (pulsing placeholder), cr-progress (indeterminate gliding bar, or filled bar with an optional counting percentage), cr-progress-steps (checked steps and a spinner on the current one), cr-loader (spinner or bouncing ball) and cr-image (blur-up image).
- 0b8113e: Add cr-input, cr-select and cr-checkbox form fields, cr-dialog and cr-drawer built on the native dialog element, and cr-card. New tokens for border, muted text, overlay, shadow and large radius.
- a8c3473: Add four components: cr-confirm (a risky action's button turns into an inline question with Confirm and Cancel, focus on Cancel, Escape restores the button), cr-hover-card (link preview opened on hover after a delay or on keyboard focus, hoverable, closed with Escape), cr-code-block (code with a Copy button announced to screen readers, keyboard-scrollable) and cr-kbd (keys and shortcuts, Mod shown as ⌘ on Mac and Ctrl elsewhere). New token `--cr-font-mono`.
- 8cd5b6d: cr-segmented gains a tabs mode: with cr-tab-panel children instead of option elements, it renders the W3C tabs pattern with automatic activation (arrow keys, Home, End, single Tab stop) and shows the chosen panel, which slides in from the side of the change (no slide when less motion is requested). `value` and `crChange` name the chosen tab by its panel's `value`, or else its position as a string; in this mode the control sends nothing with a form. All four variants and `fit` work in both modes, `underline` giving the classic tabs look. Other panels are hidden from the shadow DOM, so server rendering shows the right panel without a flash. Adds cr-tab-panel (`label`, `value`, default slot).
- d601588: Add cr-segmented, a segmented control (radio group) with a spring-sliding thumb and four variants (thumb, clip text where labels turn white only under the thumb, underline, outline), optional counts that count up and pop when picked, and a fit mode where segments hug their labels and the thumb resizes.
- a2377f2: Add cr-button with primary, secondary, outline and link variants, sizes (xs, s, m, l), disabled and loading states, start/end icon slots, full-width option and native form submit/reset.
- 5ce06c8: Add cr-slider, a form-associated range input built on a native input type="range" (keyboard and slider role for free) with a visible label, min, max, step, crInput while dragging and crChange on release. The filled part of the track follows the value, and a value bubble follows the thumb and grows while dragging or focused, without transition when less motion is requested.
- 6fc5857: Add cr-file-upload, a form-associated drop zone laid over a real native file input (click, Enter, Space, Tab), with a visible label, hint, accept also enforced on dropped files, multiple to add files up or replace the single one, and a list of chosen files with their size and a Remove button that hands focus to the next file. Each file is submitted under name, crChange gives the File[], and additions, removals and rejections are announced. The zone breathes while files are dragged over it and each file slides into the list; with less motion, only colours change.
- 099835c: Add an `error-animation` prop to every form field with an error message (cr-input, cr-textarea, cr-otp, cr-select, cr-tag-input, cr-card-input, cr-checkbox, cr-radio-group, cr-date-picker, cr-file-upload). It animates the error when it appears and again on every rejected submit: none (default, unchanged), zigzag (the bottom edge buzzes as a red zigzag, then settles flat), pop (a red "!" badge springs out with a few sparks), drop (the message drops in and swings like a hanging sign), echo (the border flashes red twice and sends out two widening echoes), jitter (the letters of the message hop one after another; screen readers still get one sentence) and wobble (the field rocks like jelly). The message is never faded in, nothing moves when less motion is requested, and in forced colors mode the field in error gets a system-coloured outline.
- 79a598f: Add cr-stepper and cr-step: progression through steps with Précédent / Suivant navigation, next(), previous(), goTo(), crStepChange and crComplete, and six styles: line (glowing bead), number (split-flap number), path (zigzag), blocks (rising stairs with a hopping ball), gauge (springing needle) and timeline (vertical). Step changes are announced and focus follows the current step.
- 6195a47: Add cr-empty-state for screens with nothing to show: a heading, a description as content, an actions slot for the way out, and an optional decorative illustration (search, inbox, error). The search illustration is the "no results" magnifier of cr-search, now shared. The illustration floats gently three times (under 5 seconds) then stops; it stays still when less motion is requested.
- 4049891: Add cr-popover, a small non-modal panel (role="dialog") anchored to its button, for interactive content: aria-expanded and aria-controls on the button, focus moved into the panel on opening and back to the button on closing, closed by Escape, a click outside, tabbing out or setting open to false, with crToggle for user changes. It scales out of the button with a spring, and simply appears when less motion is requested.
- 2d9366e: cr-dialog and cr-drawer now close when the dimmed background next to them is clicked; set closeOnBackdrop to false to prevent it. The press must also start outside, so a text selection that ends outside or a keyboard click does not close it.
- a6c4f33: Add cr-breadcrumb: write the levels as plain children (`<a href>` links, then the current page), and the component puts them in an ordered list inside a navigation landmark named "Breadcrumb", marks the last one with aria-current="page" and draws decorative separators. Links stay native light-DOM links. Beyond max levels (4 by default) the middle ones collapse behind a "…" button with aria-expanded; revealing them moves focus to the first revealed link, and they slide out of the ellipsis one after the other (no slide when less motion is requested).
- c4838f5: Add cr-background, a container that shows its content on top of a decorative animated background in the theme colours: aurora (default), gradient, grid, dots and waves in CSS, particles in a canvas, which move away from the pointer and link to it (interactive={false} turns it off). The colours derive from the primary colour and can be overridden with --cr-background-color-1/2/3 and --cr-background-base. The animated layer is hidden from screen readers and in forced colours; a pause button (aria-pressed, hidden with controls={false}) and the paused prop stop it, it starts paused when less motion is requested, and it stops off screen or in a hidden tab. The server HTML already shows a still frame.
- 523e0a0: Add cr-chart: grouped columns, horizontal bars, lines, areas and donut, with a colour-blind-checked palette (`--cr-color-chart-1` to `8`, light and dark), a legend from two series, hover and keyboard tooltips announced to screen readers, a "Show data" table, value formatting through `Intl.NumberFormat` options, and growing/drawing animations that stop when reduced motion is requested.
- 703ca97: Add cr-tooltip, a short text hint around a button, a link or a cr-button following the W3C tooltip pattern: shown on keyboard focus and after a short hover delay, hoverable, closed with Escape from anywhere, and exposed as the trigger's description. It grows out of the trigger side with a slight spring, at full size straight away when less motion is requested. The cr-icon-button tooltip now shares the same styles and motion.
- 5a6f085: Add cr-switch, a form-associated on/off switch built on a native checkbox with role="switch": the knob stretches while it slides and its cross morphs into a check mark, with no motion when less is requested.
- d3e1938: cr-select gains opt-in multiple selection (values array, checkbox options, list stays open, every value sent with the form) and an opt-in search field that filters options ignoring accents and case. Without these props it stays a simple list.
- 5db93c0: Add cr-menu (W3C menu button pattern) and an animation prop shared by cr-menu and cr-select: fade, anchor-pop, turn-over, card-deal, drum-roll, outline-trace and tile-build, with a plain fade under reduced motion.
- 77f34e1: Add cr-weather (React CrWeather), a frosted glass card where the weather happens on the glass, behind the application's content: condition is clear (default, a soft sun and a glint sweeping the glass), rain (drops bead, merge and run down leaving trails), storm (heavy rain, no lightning), fog (condensation the pointer wipes away, which slowly fogs over again), frost (ice crystals growing in from the edges), heat (a rising warm glow and shimmering highlights) or wind (streaks, specks and leaves blown across); changing it cross-fades between effects. Everything is drawn in one canvas, only while the card is on screen, the tab visible and the animation not paused. The glass is opaque enough, and its backdrop filter narrows what is behind it, for text in --cr-color-text to keep 4.5:1 on every frame, in the light and dark themes; colours can be changed with --cr-weather-glass, --cr-weather-tint and --cr-weather-warm. The weather layer is hidden from screen readers; the same pause button as cr-background (now shared) and the paused prop stop it, it starts paused on a still frame when less motion is requested, and in forced colours the glass becomes a plain Canvas panel without the effect.
- f043e97: Add cr-sparkline, a small inline line chart (line or area) drawn at its real pixel size. It is an image named by its required label and a summary of the values in the page language (last value, minimum, maximum, trend). The line draws itself on first display and, when values change, morphs point by point to the new ones (interpolated in JavaScript, so it works in every browser); no drawing and no morph when less motion is requested.
- 87c19a1: Add cr-number, an inline number that animates when its value changes: roll (odometer, default), flap (split-flap board), blur (the number slides away with a motion blur), stagger (changed digits swap one by one with a spring), decode (digits scramble then lock in) and count (counts to the new value, tinted green or red with a fading arrow). It is formatted with Intl.NumberFormat in the component language with decimals digits; separators stay still and only digits animate. It inherits the font size, weight and colour around it. The server HTML already shows the formatted value, nothing moves on first render or when less motion is requested, and screen readers and copy read a hidden final value, never the intermediate digits.
- 5ac45e5: Add cr-rating, a form-associated star rating built as a radio group (single Tab stop, arrow keys that wrap, Home and End), each star named "3 stars out of 5", with a visible label, value, max, disabled and readonly (shown as an image named "Rating: 4 out of 5"). Stars fill in a wave up to the chosen one, which bounces, and hovering previews a rating; no motion when less motion is requested.
- 5a24a6f: Add an `animation` prop to cr-otp: pop (default, unchanged), bounce (the digit drops in, the box squashes and bounces back, boxes hop when complete), stretch (a single focus ring stretches from box to box, then wraps the whole code), spin (digits roll in like a slot-machine reel and spin again in a wave when complete), merge (when complete, the boxes slide together into one rounded success bar), zoom (the digit zooms in from big, a shine sweeps across when complete) and tint (the box fills with colour from the bottom, turning green when complete). A pasted code arrives as a quick cascade, Backspace undoes the complete state, nothing moves when less motion is requested, and the single real input stays the only control screen readers see.
- fd486d6: Add cr-pagination: a navigation landmark named "Pagination" with previous and next arrows, page numbers named "Page 4", the current one marked with aria-current="page", and an ellipsis for long ranges (1 … 4 5 6 … 20). With an href template ("/products?page={page}") every page is a real link, so Ctrl/Cmd+click and middle click are native; without it, buttons emit crChange. The ringed highlight of the current page slides to the new number; no slide when less motion is requested.
- a3e2104: Add cr-command-palette: a modal dialog (native dialog) opened with Ctrl+K / ⌘K (shortcut, on by default) or open, holding a combobox that filters child option elements, accent and case insensitive, grouped under headings with data-group. Up/Down (skipping disabled commands), Enter and Escape follow the APG combobox pattern with aria-activedescendant; "No results" reuses cr-empty-state in a status region; focus goes back to where it was on close. Emits crSelect and crClose. The dialog drops in with a spring and the active highlight slides between rows; neither moves when less motion is requested. readOptions now also reads data-group.
- 0ad3dbd: cr-command-palette: the letters that match the search turn bold and coloured, like in cr-select (`match` part).
- 35da46a: Add cr-badge, a small status or count pill: slotted text, neutral, primary, success and danger variants (tinted background and same-hue text at 4.5:1 or more), and an optional count that rolls through the numbers in between like an odometer when it changes (jumping straight to the value when less motion is requested). Screen readers read the final number only; with live, the badge becomes a polite status region that announces each change. countUp (shared with cr-segmented counters) can now start from a given number.
- dc4e9f0: Add cr-quantity, a form-associated quantity picker: a number between round − and + buttons in a pill, following the APG spinbutton pattern (arrows, Page Up/Down, Home/End, typed numbers committed on Enter or blur and clamped). Props: label, name, value, min, max, step, hint, error, required, disabled, error-animation and animation: press (default, the button squishes and the number pops up), slide (the number slides in from the tapped side), ripple (a ripple from the button reveals the number), stretch (the pill stretches toward the button, the number wobbles), spin (the glyph turns half a turn, the number flips over) or halo (a glow ring bursts, the number zooms down). Range, step and required errors are translated; the buttons are named after the label, stay focusable with aria-disabled at the bounds, and button changes are announced through a polite live region. crInput fires on every new value, crChange on every committed one. Nothing moves when less motion is requested, and numbers never fade in from transparent.
- 628f8e0: cr-select gains opt-in server-side search: with `remote` (alongside `searchable`) the list no longer filters locally and emits `crSearch` 300 ms after the last keystroke; `loading` shows and announces "Recherche en cours…". Chosen options keep their label in the button when they leave the results.
- 9b7280f: cr-select with searchable highlights the letters of each option that match the search (bold, theme colour, ignoring accents and case like the filter), exposed as ::part(match).
- 82d4cc2: Add cr-search, an animated search field with four variants (outline, filled, underline, and expand where a round magnifier button stretches into the field): the magnifier morphs into a clear arrow on focus, placeholder words roll (at most four times), recent searches show as chips that fly into the field, and a "no results" state where the magnifier shakes and a "?" pops up. cr-loader gains variant="search", a gliding magnifier.
- 0b52a64: Add cr-date-picker, a form-associated date field: typing in the page language format (DD/MM/YYYY in French, MM/DD/YYYY in English, shown as a hint) or picking from a calendar dialog following the WAI-ARIA APG Date Picker Dialog pattern (arrows by day and week, Page Up/Down by month, Shift for a year, Home/End within the week, Escape returns focus to the button). ISO value, min, max and required with built-in validation messages; month and weekday names come from Intl, weeks start on Monday in French. Months slide in from the side of navigation and the selected day pops, without motion when less motion is requested.
- 9e586dd: Add cr-grid-layout and cr-grid-item: a grid of items users rearrange by dragging a handle (or by holding the click anywhere on a card) and resize from the corner, with grid cells and a drop placeholder shown while dragging, other items moving aside then compacting upwards, keyboard moves and resizes with announcements, localStorage persistence, reset(), first-free placement for new items, removable items and full-width stacking on narrow screens.
- 09cec26: cr-table: column sorting (`sortable`, S key, `sort` prop, `crSortChange`), row selection (`selectable`, `selected`, `rowKey`, `crSelectionChange`), clickable rows through a real button in the `primary` column (`crRowClick`), value formatting that keeps raw values for sorting (`format`), and custom cells filled by `slot="<key>-<id>"` children (`slot` columns).
- 1011ebb: Add cr-table: a real table whose columns each user can reorder (drag or Alt + arrows), resize (handle, Shift + arrows, Enter or double-click to fit), pin to the left and hide, with three row densities, a reset button, a layout summary, announced actions and optional localStorage persistence (storageKey, crLayoutChange). Five styles (default, striped, cards, minimal, grid), sticky header and coloured status badges per column.
- a88b956: Theming takes one variable: --cr-color-primary. Hover, subtle background, readable text, focus and the text color on primary are derived in CSS, and the cr-theme class scopes a theme to one area. Components use the readable text shade for text, borders and focus.
- 6c1fc4d: Add an opt-in dark theme. `@cristal/tokens/tokens-dark.css` (also shipped as `@cristal/react/tokens-dark.css`) gives dark values to surface, text, muted text, borders, disabled states, danger, success, overlay and shadow, and sets `color-scheme: dark`, under `:root[data-theme='dark']` and the `cr-theme-dark` class; nothing changes without them, whatever the system preference. The primary colour stays the brand colour; primary-text, focus and the new primary-indicator token (stars, slider, switch, radio, checkbox, loader, sparkline, drop zones) switch to a light shade of it, and primary-subtle mixes with the dark surface. Status texts of badges, chips, inputs, numbers and codes now use the new text-lightness tokens, so they stay readable in both themes, and the icon button badge text follows the danger colour. Text keeps 4.5:1 and borders, focus and indicators 3:1 in dark.
- 4fe8735: Form fields show French validation messages automatically and focus the first invalid field on submit. cr-select is now a custom accessible listbox (W3C combobox pattern) shown above the page. Violet is the default primary color.
