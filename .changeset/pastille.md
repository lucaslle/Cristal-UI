Add cr-badge, a small status or count pill: slotted text, neutral, primary, success and danger variants (tinted background and same-hue text at 4.5:1 or more), and an optional count that rolls through the numbers in between like an odometer when it changes (jumping straight to the value when less motion is requested). Screen readers read the final number only; with live, the badge becomes a polite status region that announces each change. countUp (shared with cr-segmented counters) can now start from a given number.
