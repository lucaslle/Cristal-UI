Add cr-file-upload, a form-associated drop zone laid over a real native file input (click, Enter, Space, Tab), with a visible label, hint, accept also enforced on dropped files, multiple to add files up or replace the single one, and a list of chosen files with their size and a Remove button that hands focus to the next file. Each file is submitted under name, crChange gives the File[], and additions, removals and rejections are announced. The zone breathes while files are dragged over it and each file slides into the list; with less motion, only colours change.
