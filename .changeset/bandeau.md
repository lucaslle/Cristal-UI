Add cr-alert, an inline message banner with info, success, warning and danger variants, an optional heading and an optional Close button that emits crClose. The message is a status region (an alert region for danger), its type is shown by a distinct icon and a prefix read by screen readers ("Error: "), not by colour alone. When inserted after page load the banner unfolds in height, and its icon draws itself; no motion when less motion is requested.
