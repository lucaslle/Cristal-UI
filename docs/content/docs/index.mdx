Cristal est une bibliothèque de composants d'interface écrits une seule fois en **Web Components** (avec Stencil), puis livrés avec des wrappers natifs pour **React** et **Next.js**.

## Principes

- **Accessible par défaut.** Les composants s'appuient sur les éléments natifs du navigateur (`button`, `input`, `select`, `dialog`) : clavier, lecteurs d'écran et mobile fonctionnent sans effort. Chaque composant est audité automatiquement avec axe (WCAG 2.1 AA, base du RGAA).
- **Rendu serveur.** Avec Next.js, les composants arrivent déjà dessinés dans le HTML : pas de flash au chargement.
- **Personnalisable.** Couleurs, espacements et rayons passent par des variables CSS (les design tokens) : un fichier CSS suffit pour adopter votre identité visuelle.
- **Formulaires natifs.** Les champs participent au `<form>` parent comme des champs HTML : valeur envoyée, validation, réinitialisation.
