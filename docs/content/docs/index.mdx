Cristal is a library of UI components written once as **Web Components** (with Stencil), then shipped with native wrappers for **React** and **Next.js**.

## Principles

- **Accessible by default.** Components build on the browser's native elements (`button`, `input`, `select`, `dialog`): keyboard, screen readers and mobile work out of the box. Every component is audited automatically with axe (WCAG 2.1 AA, the basis of RGAA).
- **Server rendering.** With Next.js, components arrive already rendered in the HTML: no flash on load.
- **Customizable.** Colors, spacing and radii go through CSS variables (design tokens): a single CSS file is enough to apply your visual identity.
- **Native forms.** Fields take part in the parent `<form>` like HTML fields: value submission, validation, reset.
