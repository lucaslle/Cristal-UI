## Une seule couleur à choisir

Pour donner votre couleur à toute l'application, une ligne suffit, après l'import de `@cristal/react/tokens.css` :

```css title="theme.css"
:root {
  --cr-color-primary: #e11d48;
}
```

Toutes les autres nuances sont **calculées automatiquement** à partir de cette couleur :

- le survol (plus foncé pour une couleur foncée, plus clair pour une couleur claire) ;
- le fond clair des boutons secondaires et des options survolées ;
- une version assez foncée pour être lue comme texte, contour ou indicateur de focus sur fond blanc ;
- la couleur du texte posé sur la couleur principale : blanc sur une couleur foncée, noir sur une couleur claire.

## Générateur de thème

## Un thème pour une partie de la page

Ajoutez la classe `cr-theme` à un conteneur et redéfinissez la couleur sur ce conteneur : seuls les composants qu'il contient changent.

```tsx
<section className="cr-theme" style={{ '--cr-color-primary': '#0f766e' }}>
  <CrButton>Bouton sarcelle</CrButton>
</section>
```

<Callout type="warn">
  Le générateur vérifie les contrastes de votre couleur. Les couleurs de milieu de gamme (ni vraiment claires, ni vraiment foncées) peuvent rester sous le seuil de 4,5:1 : le générateur l'indique alors.
</Callout>

### Parts CSS

Pour un réglage plus fin, chaque composant expose des **parts** stylables depuis l'extérieur avec `::part()`. Elles sont listées en bas de chaque page de composant.

```css
cr-input.search::part(label) {
  color: white;
}
```
