## Une seule couleur à choisir

Pour donner votre couleur à toute l'application, une ligne suffit, après l'import de `@cristal/react/tokens.css` :

```css title="theme.css"
:root {
  --cr-color-primary: #e11d48;
}
```

Toutes les autres nuances sont **calculées automatiquement** à partir de cette couleur :

- le survol (plus foncé pour une couleur foncée, plus clair pour une couleur claire) ;
- le fond clair des boutons secondaires et des options survolées ;
- une version assez foncée pour être lue comme texte, contour ou indicateur de focus sur fond blanc ;
- la couleur du texte posé sur la couleur principale : blanc sur une couleur foncée, noir sur une couleur claire.

## Un thème pour une partie de la page

Ajoutez la classe `cr-theme` à un conteneur et redéfinissez la couleur sur ce conteneur : seuls les composants qu'il contient changent.

```tsx
<section className="cr-theme" style={{ '--cr-color-primary': '#0f766e' }}>
  <CrButton>Bouton sarcelle</CrButton>
</section>
```

<Callout type="warn">
  Le générateur vérifie les contrastes de votre couleur. Les couleurs de milieu de gamme (ni vraiment claires, ni vraiment foncées) peuvent rester sous le seuil de 4,5:1 : le générateur l'indique alors.
</Callout>

## Thème sombre

Le thème sombre est **optionnel** : importez sa feuille après celle des jetons, puis posez `data-theme="dark"` sur `<html>`. Sans cet attribut, rien ne change, même si le système de l'utilisateur est en mode sombre : c'est vous qui décidez quand l'activer.

```tsx title="app/layout.tsx"
import '@cristal/react/tokens.css';
import '@cristal/react/tokens-dark.css';

<html lang="fr" data-theme="dark">
```

- La surface, le texte, les bordures, les états désactivés, le danger, le succès, le voile et l'ombre prennent des valeurs sombres, et `color-scheme: dark` adapte les contrôles natifs et les barres de défilement.
- **Votre couleur principale ne change pas** : les boutons pleins gardent votre marque. Ses dérivées s'adaptent : le texte, le contour de focus et les indicateurs (étoiles, curseur, interrupteur, case cochée) passent à une nuance claire de votre couleur, et le fond des boutons secondaires se mélange à la surface sombre au lieu du blanc.
- Les contrastes restent ceux du thème clair : 4,5:1 au moins pour le texte, 3:1 pour les bordures, le focus et les indicateurs.

Les valeurs qui changent en sombre (les autres restent celles du thème clair) :

<TokenTable prefix="--cr-" theme="dark" lang="fr" />

Pour une seule zone, la classe `cr-theme-dark` applique le thème sombre à un conteneur ; `cr-theme` y remet le thème clair. Dans une page sombre, donnez donc votre couleur locale avec `cr-theme-dark` :

```tsx
<section className="cr-theme-dark" style={{ '--cr-color-primary': '#0f766e' }}>
  <CrButton>Bouton sarcelle, version sombre</CrButton>
</section>
```

Pour laisser l'utilisateur choisir, la [bascule de thème](/docs/composants/bascule-theme) pose l'attribut, avec une transition animée.

### Parts CSS

Pour un réglage plus fin, chaque composant expose des **parts** stylables depuis l'extérieur avec `::part()`. Elles sont listées en bas de chaque page de composant.

```css
cr-input.search::part(label) {
  color: white;
}
```
