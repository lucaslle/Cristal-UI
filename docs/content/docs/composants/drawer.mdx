## Example

Works like the [dialog](/docs/composants/modale), but the panel takes the full height, on the right edge (`placement="end"`, default) or the left edge (`placement="start"`). Its width is set with the `--cr-drawer-width` CSS variable (400px by default, never wider than the screen).

## Accessibility

Same guarantees as the dialog: focus trapped then restored, Escape, inert page and blocked scrolling, title as the panel's name.
