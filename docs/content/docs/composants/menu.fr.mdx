## Animations

La propriété `animation` choisit l'effet d'ouverture et de fermeture. Elle existe aussi sur la [liste déroulante](/docs/composants/liste-deroulante#animations). Ouvrez chaque menu pour comparer.

<Preview>
  <MenuAnimations />
</Preview>

| Valeur | Effet |
|---|---|
| `fade` | fondu discret (par défaut) |
| `anchor-pop` | le menu jaillit du bouton avec un léger rebond, et s'y rétracte au choix |
| `turn-over` | le panneau se retourne comme une carte |
| `card-deal` | les actions sont distribuées comme des cartes ; celle choisie vole jusqu'au bouton |
| `drum-roll` | les actions arrivent en tournant sur un tambour, puis repartent vers le bas |
| `outline-trace` | un contour violet → cyan dessine le panneau, puis les lignes apparaissent en balayage |
| `tile-build` | le panneau se construit en tuiles par vagues, puis éclate |

<Callout>
  Si l'utilisateur a demandé à son système de réduire les animations, toutes deviennent un simple fondu. Les animations durent moins d'une demi-seconde et n'empêchent jamais d'utiliser le clavier.
</Callout>

## Clavier

| Touche | Bouton | Menu ouvert |
|---|---|---|
| Entrée, Espace, flèche bas | ouvre le menu sur la première action | choisit l'action |
| Flèche haut | ouvre le menu sur la dernière action | action précédente |
| Flèche bas | — | action suivante |
| Début / Fin | — | première / dernière action |
| Lettres | — | va à l'action qui commence par ces lettres |
| Échap | — | ferme et rend le focus au bouton |
| Tab | — | ferme et passe à l'élément suivant |

## Accessibilité

- Suit le modèle « menu button » du W3C (ARIA Authoring Practices) : `aria-haspopup="menu"`, `aria-expanded`, rôles `menu` et `menuitem`.
- Le focus entre dans le menu à l'ouverture et revient au bouton après un choix ou Échap.
- Les actions indisponibles (`disabled`) sont annoncées et ignorées par la navigation.
- Quand plusieurs menus ont le même libellé (un menu « Actions » par ligne de tableau), donnez à chacun un nom précis avec `accessibleLabel` : « Actions pour Clavier », « Actions pour Souris »… Ce nom doit **contenir le libellé visible** (WCAG 2.5.3), pour que les personnes qui pilotent leur ordinateur à la voix puissent dire « Actions ».
- Le menu s'affiche au-dessus de la page : jamais coupé par un conteneur ou une modale, il s'ouvre vers le haut quand la place manque. Dans une modale, Échap ferme le menu sans fermer la modale.
