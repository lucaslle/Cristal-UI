## Exemple

Chaque `CrGridItem` a un titre (`label`), une position (`x`, `y`, en cases à partir de 0) et une taille (`w` colonnes, `h` lignes). L'utilisateur le déplace en l'attrapant n'importe où (ou par sa poignée ⠿), et change sa taille en tirant son coin : la grille apparaît, l'emplacement visé est dessiné en pointillés, les autres éléments s'écartent pendant le déplacement puis tout se tasse vers le haut.

## Attraper une carte

La propriété `grab` de `CrGridLayout` choisit comment la souris attrape une carte :

| `grab` | Comportement |
|---|---|
| `surface` (défaut) | n'importe où sur la carte : le déplacement commence dès que le pointeur bouge |
| `hold` | n'importe où, après un appui maintenu un instant (300 ms) sans bouger ; un clic suivi d'un mouvement rapide sélectionne du texte comme d'habitude |
| `handle` | par la poignée ⠿ seulement |

Dans tous les cas, la poignée ⠿ déplace la carte tout de suite, et appuyer sur un bouton, une case à cocher, un lien, un champ ou une barre de défilement de la carte ne la déplace pas. Au doigt, sur écran tactile, seule la poignée déplace la carte : glisser sur la carte fait défiler la page.

| `variant` | Apparence |
|---|---|
| `card` (défaut) | carte bordée, ombre légère |
| `elevated` | sans bordure, une ombre douce qui grandit au survol |
| `soft` | teintée de la couleur principale, titre coloré |
| `outline` | simple contour, la carte laisse voir le fond |
| `glass` | verre dépoli : à poser sur un fond coloré ou une image, assez clair ou sombre pour que le texte reste lisible |

| `resizeHandle` | Poignée |
|---|---|
| `corner` (défaut) | un arc qui épouse le coin arrondi de la carte |
| `knob` | une pastille ronde sur le coin |
| `edges` | le coin, plus les bords droit (largeur seule) et bas (hauteur seule) ; une barre apparaît sur le bord survolé |

## Grille

| Propriété de `CrGridLayout` | Rôle |
|---|---|
| `columns` | nombre de colonnes (12 par défaut) |
| `rowHeight` | hauteur d'une ligne en pixels (80 par défaut) |
| `gap` | espace entre les éléments en pixels (16 par défaut) |
| `editable` | `false` pour figer la disposition (sans poignées) |
| `grab` | où attraper une carte à la souris : `surface`, `hold` ou `handle` |
| `stackBelow` | largeur en pixels sous laquelle les éléments s'empilent (480 par défaut) |
| `storageKey` | retient la disposition de l'utilisateur d'une visite à l'autre |

`onCrLayoutChange` donne la disposition (`id`, `x`, `y`, `w`, `h` de chaque élément) après chaque changement, pour l'enregistrer côté serveur par exemple ; la méthode `reset()` revient à la disposition de départ.

## Éléments

- Donnez un `id` à chaque élément : c'est lui qui retrouve sa place dans la disposition enregistrée.
- Sans `x` ni `y`, un élément prend la première place libre : pratique pour ajouter un élément depuis une liste.
- `minW`, `minH`, `maxW` et `maxH` bornent la taille ; `removable` ajoute un bouton × qui émet `onCrRemove` (retirez alors l’élément de votre liste).
- Le slot `actions` place des boutons dans l'en-tête.
- Quand le contenu dépasse la carte, il défile ; la zone reçoit alors le focus (Tab), puis se fait défiler avec les flèches, Page suivante et Page précédente.

## Clavier

Sur la poignée d’un élément (Tab) :

| Touche | Action |
|---|---|
| ← → ↑ ↓ | déplace l’élément d'une case |
| Maj + ← → | une colonne de moins ou de plus |
| Maj + ↑ ↓ | une ligne de moins ou de plus |

Chaque changement est annoncé : « Ventes : colonne 3, ligne 1. », « Ventes : 4 colonnes sur 3 lignes. ».

## Petit écran

Sous 480 pixels de large (`stackBelow` pour changer ce seuil), les éléments s'empilent sur toute la largeur, dans l'ordre de la grille, et les poignées disparaissent.

<Callout>
  Si l'utilisateur a demandé à son système de réduire les animations, les éléments changent de place sans glisser.
</Callout>
