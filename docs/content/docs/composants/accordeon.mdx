## Example

Each section is a `CrAccordionItem` with a `label`. For a multi-step flow, use the [Stepper](/docs/composants/etapes) component instead. By default, opening a section closes the others; with `multiple`, several can stay open. `open` opens a section initially, and `onCrToggle` reports each opening or closing (`event.detail` is `true` when opening).

## Open all

With `toggleAll`, an "Open all" button opens the sections one after another, then "Close all" closes them in reverse order. Several sections can then stay open.

## Side-by-side panels

With `variant="panels"`, the sections are vertical panels: the selected one widens, the others fold into strips with their title written vertically. One panel is always open, the first one by default. The height is set with the `--cr-accordion-height` CSS variable (280px by default), the strip width with `--cr-accordion-fold` (56px).

## Animations

| `animation` value | Effect |
|---|---|
| `slide` | the section unfolds smoothly (default) |
| `accent-bar` | a gradient bar grows along the open section, and its number lights up (with `numbered`) |
| `cascade` | the content comes in line by line; `data-cr-count` elements count up to their value and `data-cr-grow` elements grow from the bottom |

With `cascade`, `data-cr-count` gives the final value (`"19.9"`) of an element that contains only text: the first number in the text counts up from 0 to it, then the original text is restored. The `meta` slot displays a value to the right of the title, here the total or the statistic.

## Keyboard

| Key | Action |
|---|---|
| Enter, Space | opens or closes the section |
| Down / Up Arrow (Right / Left) | next / previous section header |
| Home / End | first / last header |
| Tab | moves to the next header or content |

## Accessibility

- Follows the W3C "accordion" pattern (ARIA Authoring Practices): each header is a button inside a level 3 heading (`headingLevel` to change it), which states whether it is open (`aria-expanded`) and controls a region named by that header.
- A closed section is removed from the keyboard order and from screen readers.
- The chart in the "cascade" example has a `role="img"` and a description: do the same for your own visuals.
