## Example

Each word confirmed with Enter or a comma jumps into a chip; × removes it, and Backspace in the empty field removes the last one. Pasted text with commas ("ui, motion, design") gives several chips; a duplicate is rejected. `values` reads and sets the list, `onCrChange` gives it on every change.

`error-animation` animates the error when it appears and on every rejected submit (zigzag, badge, echo…): see [Animated error](/docs/composants/champ-texte#animated-error).

## Accessibility

- The chips form a named list; each × is a "Remove design" button.
- Every addition or removal is announced: "ui added. 3 tags.".
- The form receives one value per tag under the same `name`; with `required`, at least one tag is needed.
