## Automatic validation

Input errors appear on their own (in English by default, in French with `lang="fr"`) **when the user leaves the field** after changing it, or **when they try to submit** the form. They disappear as soon as the input is fixed.

| Case | Message |
|---|---|
| Empty required field | This field is required. |
| Malformed `type="email"` | Enter a valid email address, for example name@domain.com. |
| Malformed `type="url"` | Enter a valid web address, for example https://example.com. |
| Non-numeric `type="number"` | Enter a number. |

On submit, focus moves to the **first invalid field**, and its message is read by screen readers. For an error coming from the server ("this address is already in use"), pass your own message with `error`: it replaces the automatic message.

## Animated error

`error-animation` (`errorAnimation` in React) animates the error when it appears, then again on **every rejected submit**, even when the message is the same. Pick an animation, then click Continue with the field empty or an incomplete address.

| `error-animation` | Effect |
|---|---|
| `none` | no animation (default) |
| `zigzag` | the bottom edge of the field snaps into a buzzing red zigzag, then settles flat |
| `pop` | a red "!" badge springs out at the end of the field with a few sparks, and stays |
| `drop` | the message drops in and swings from its top-left corner, like a hanging sign |
| `echo` | the border flashes red twice and sends out two widening echoes |
| `jitter` | the letters of the message hop and shiver one after another |
| `wobble` | the field rocks like jelly, then settles |

The same prop exists on the [text area](/docs/composants/zone-de-texte), [one-time code](/docs/composants/code), [select](/docs/composants/liste-deroulante), [tags](/docs/composants/etiquettes), [payment card](/docs/composants/carte-bancaire), [checkbox](/docs/composants/case-a-cocher), [radio group](/docs/composants/boutons-radio), [date picker](/docs/composants/selecteur-de-date), [quantity picker](/docs/composants/quantite) and [file upload](/docs/composants/depot-de-fichiers). On the checkbox and the radio group, the zigzag runs under the box and its label, the badge sits after them and the whole block wobbles; on the one-time code, the badge follows the last box and the echoes wrap all the boxes; on the file upload, the animation plays on every rejected file.

Screen readers still get the message as one sentence (with `jitter`, the hopping letters are a hidden copy), and it stays readable at every frame: it moves, but never fades in from transparent. When the user asks for less motion (`prefers-reduced-motion`), nothing moves: the red border and the message appear at once, with no sparks or echoes. In forced colors mode, the field in error gets a system-coloured outline.

## Password strength and completion

- With `strength` (for `type="password"`), a four-segment meter fills up and changes color while typing; the level is written out and announced: "Strength: Good". The score takes into account length, upper and lower case, digits and symbols.
- With `completions`, the rest of the first suggestion that extends the input is shown in gray behind the text. Right Arrow or a click on it accepts it: it is filled in, and "Filled in for you" is shown. The field is marked `aria-autocomplete="inline"` and the suggestion is read with the field description.

## In a form

Cristal fields take part in the parent `<form>` like native fields: their value is submitted under their `name`, `required` blocks submission, `type="reset"` restores their initial value, and **Enter** in a text field submits the form.

## Accessibility

- Label linked to the field: clicking the label puts the cursor in the field.
- `hint` and `error` linked with `aria-describedby`; `error` adds `aria-invalid="true"` and a red border (the error does not rely on color alone: the message is displayed).
- The asterisk on required fields is hidden from screen readers, which already announce "required".
- Use `autocomplete` (`email`, `name`, `tel`…) to help autofill.
