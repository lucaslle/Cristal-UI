## Animations

The `animation` property picks the opening and closing effect. It is also available on the [select](/docs/composants/liste-deroulante#animations). Open each menu to compare.

<Preview>
  <MenuAnimations />
</Preview>

| Value | Effect |
|---|---|
| `fade` | subtle fade (default) |
| `anchor-pop` | the menu springs out of the button with a slight bounce, and shrinks back into it on selection |
| `turn-over` | the panel flips over like a card |
| `card-deal` | the actions are dealt like cards; the chosen one flies back to the button |
| `drum-roll` | the actions roll in on a drum, then roll away downwards |
| `outline-trace` | a purple → cyan outline draws the panel, then the items sweep in |
| `tile-build` | the panel builds up in waves of tiles, then bursts apart |

## Keyboard

| Key | Button | Open menu |
|---|---|---|
| Enter, Space, Down Arrow | opens the menu on the first action | selects the action |
| Up Arrow | opens the menu on the last action | previous action |
| Down Arrow | — | next action |
| Home / End | — | first / last action |
| Letters | — | moves to the action starting with those letters |
| Escape | — | closes and returns focus to the button |
| Tab | — | closes and moves to the next element |

## Accessibility

- Follows the W3C "menu button" pattern (ARIA Authoring Practices): `aria-haspopup="menu"`, `aria-expanded`, `menu` and `menuitem` roles.
- Focus moves into the menu when it opens and returns to the button after a selection or Escape.
- Unavailable actions (`disabled`) are announced and skipped by navigation.
- When several menus share the same label (an "Actions" menu on each table row), give each one a specific name with `accessibleLabel`: "Actions for Keyboard", "Actions for Mouse"… This name must **contain the visible label** (WCAG 2.5.3), so that people who control their computer by voice can say "Actions".
- The menu is displayed above the page: it is never clipped by a container or a dialog, and it opens upwards when space runs out. Inside a dialog, Escape closes the menu without closing the dialog.
