## Exemple

Même fonctionnement que la [modale](/docs/composants/modale), mais le panneau occupe toute la hauteur, sur le bord droit (`placement="end"`, par défaut) ou gauche (`placement="start"`). Sa largeur se règle avec la variable CSS `--cr-drawer-width` (400px par défaut, jamais plus large que l'écran).

## Accessibilité

Mêmes garanties que la modale : focus piégé puis restauré, Échap, page inerte et défilement bloqué, titre comme nom du panneau. Avec `closeOnBackdrop`, un clic sur le fond assombri, à côté du panneau, le ferme aussi (désactivé par défaut).
