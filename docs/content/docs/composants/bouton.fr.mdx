## Variantes

Une seule action **principale** par contexte (une page, ou une modale ouverte). Les autres actions prennent un niveau inférieur : secondaire, contour, puis lien.

## Tailles

La taille dépend du **conteneur**, pas de la variante : deux boutons côte à côte ont la même taille. Repères : `m` dans un formulaire ou une modale, `s` dans une carte ou une barre d'outils, `xs` dans un tableau dense, `l` pour l'action principale sur mobile.

## Icônes

Placez l'icône dans `slot="start"` (avant le libellé) ou `slot="end"` (après). Elle est dimensionnée automatiquement : 20px en `xs`, 24px sinon. Une icône décorative prend `aria-hidden="true"`.

## Dans un formulaire

`type="submit"` envoie le formulaire parent, `type="reset"` le réinitialise, comme un bouton natif. Voir l'exemple complet sur la page [Champ texte](/docs/composants/champ-texte#dans-un-formulaire).

## Accessibilité

- Bouton natif sous le capot : activable avec Entrée et Espace, annoncé comme « bouton ».
- Focus visible, contraste du libellé supérieur à 4,5:1 dans toutes les variantes.
- Le libellé doit décrire l'action : « Ajouter un produit » plutôt que « OK ».
