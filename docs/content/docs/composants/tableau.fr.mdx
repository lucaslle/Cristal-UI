## Exemple

Chaque utilisateur règle le tableau à son goût : glissez un en-tête pour déplacer la colonne, tirez le bord droit d'un en-tête pour changer sa largeur (double-clic pour l'ajuster au contenu), choisissez les colonnes affichées dans « Colonnes » et la hauteur des lignes avec « Confortable », « Normale » ou « Compacte ». « Réinitialiser » revient à la présentation de départ.

## Styles

La propriété `variant` change l'allure du tableau ; choisissez-en un dans l'exemple ci-dessus :

| Valeur | Allure |
|---|---|
| `default` | en-tête teinté, traits fins entre les lignes, légère ombre (par défaut) |
| `striped` | lignes alternées, sans traits |
| `cards` | chaque ligne est une carte posée sur un fond teinté, bordée de violet au survol |
| `minimal` | sans cadre ni fond d'en-tête, un trait marqué sous les titres |
| `grid` | toutes les cases bordées, façon tableur ; la case survolée est encadrée |

Les en-têtes restent collés en haut quand le tableau défile : fixez sa hauteur avec la variable CSS `--cr-table-max-height` (par exemple `400px`).

## Pastilles de statut

Avec `badges`, une colonne affiche certaines valeurs en pastilles colorées : `{ Payée: 'success', 'En attente': 'warning' }`. Tons disponibles : `primary`, `success`, `warning`, `danger`, `neutral`. Le texte reste lisible (contraste d'au moins 4,5:1) et la couleur n'est jamais la seule information : la valeur est toujours écrite.

## Colonnes et lignes

`columns` décrit les colonnes, dans leur ordre de départ :

| Champ | Description |
|---|---|
| `key` | clé de la valeur dans chaque ligne (obligatoire) |
| `label` | titre de la colonne (obligatoire) |
| `width` | largeur en pixels, 160 par défaut (de 64 à 640) |
| `align` | `end` pour aligner à droite, par exemple les montants |
| `pinned` | colonne fixée à gauche, qui reste visible quand le tableau défile |
| `hidden` | colonne masquée au départ |
| `badges` | valeurs affichées en pastilles, avec leur ton |
| `sortable` | l'en-tête trie les lignes |
| `format` | fonction `(valeur, ligne) => texte` pour l'affichage ; le tri garde la valeur brute |
| `primary` | la cellule devient le bouton de la ligne (voir « Trier, sélectionner, ouvrir ») |
| `slot` | la cellule affiche vos propres éléments (boutons, menus, liens) |

`rows` est un tableau d'objets, avec une valeur par `key`. Sans `format`, les valeurs sont affichées comme du texte.

- **Trier** : avec `sortable`, un clic sur l'en-tête (ou la touche S) trie par ordre croissant, puis décroissant, puis revient à l'ordre d'origine. Les nombres et les dates sont comparés par valeur, les textes dans l'ordre de la langue (« Écran » avec les E, « 10 » après « 9 ») ; les cases vides restent en bas. Gardez les valeurs brutes dans `rows` (nombres, dates) et mettez-les en forme avec `format`, pour que 1 290 € passe bien après 329 €. Le tri en cours est dans `sort` (`{ key, direction: 'ascending' | 'descending' }`), et `onCrSortChange` le donne à chaque changement.
- **Sélectionner** : `selectable` ajoute une case par ligne et une case « tout sélectionner » (à moitié cochée quand une partie seulement l'est). `selected` contient les valeurs de `rowKey` (`id` par défaut) des lignes cochées ; `onCrSelectionChange` donne la nouvelle liste.
- **Ouvrir une ligne** : la colonne `primary` affiche un bouton par ligne ; un clic sur ce bouton, ou ailleurs sur la ligne, émet `onCrRowClick` avec la ligne. Les cases, boutons et liens de la ligne gardent leur propre action.
- **Cellules libres** : pour une colonne `slot`, placez dans le tableau un enfant `slot="<key>-<id>"` par ligne, par exemple `slot="actions-3"`. Seules les lignes affichées montrent leur contenu.

## Grands volumes

Le tableau affiche d'abord 100 lignes, puis 100 de plus chaque fois que sa fin approche de l'écran pendant le défilement : des milliers de lignes s'affichent sans figer la page. Le total reste annoncé (`aria-rowcount`) et une ligne sous le tableau indique « 100 lignes sur 3 685 : la suite s'affiche en défilant. ». Quand `rows` change (un filtre, une autre période), l'affichage repart des 100 premières.

## Retenir les réglages

Avec `storageKey`, les réglages (ordre, largeurs, colonnes fixées et masquées, densité) sont enregistrés dans le navigateur et retrouvés à la visite suivante. `onCrLayoutChange` les donne aussi dans `event.detail` à chaque changement, pour les enregistrer côté serveur par exemple.

## Clavier

Placez le focus sur un en-tête avec Tab :

| Touche | Action |
|---|---|
| ← → | en-tête voisin |
| Début / Fin | premier / dernier en-tête |
| Alt + ← → | déplace la colonne |
| Maj + ← → | réduit ou élargit la colonne de 16 pixels |
| Entrée | ajuste la largeur au contenu |
| F | fixe la colonne à gauche, ou la libère |
| M | masque la colonne |
| S | trie la colonne, si elle est `sortable` |

Le pied du tableau rappelle ces raccourcis et résume la présentation : « 6 colonnes sur 7 · 1 fixée · lignes normales ».

## Animations

- La colonne attrapée vole au-dessus des autres, et un trait violet montre où elle sera posée.
- Après un déplacement, chaque colonne glisse de son ancienne place à la nouvelle.
- Une ombre apparaît sous les colonnes fixées dès que le tableau défile.

<Callout>
  Si l'utilisateur a demandé à son système de réduire les animations, les colonnes changent de place sans glisser.
</Callout>

## Accessibilité

- C'est un vrai tableau (`table`, `th scope="col"`), nommé par son titre.
- Chaque réglage à la souris a son équivalent au clavier, décrit sur chaque en-tête.
- Chaque action est annoncée : « Statut déplacée en position 3 sur 7. », « Produit fixée à gauche. », « Région masquée : 6 colonnes sur 7. ».
- Une colonne fixée est annoncée « fixée » ; au moins une colonne reste toujours affichée.
- Avec beaucoup de lignes, le nombre total est annoncé même si seules les premières sont affichées.
- La colonne triée porte `aria-sort` ; chaque tri est annoncé : « Trié par Prix, ordre croissant. ».
- Chaque case de sélection est nommée d'après sa ligne (« Sélectionner Câble USB-C ») et le nombre de lignes cochées est annoncé.
- Une ligne cliquable a toujours un vrai bouton, atteignable avec Tab : le clic sur la ligne n'est qu'un raccourci pour la souris.
