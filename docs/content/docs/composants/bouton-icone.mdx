## Variants

`label` is required: it gives the button its name for screen readers and shows in a tooltip on hover and keyboard focus. The default, `ghost` (no background), suits toolbars; `secondary`, `outline` and `primary` follow the [button](/docs/composants/bouton) hierarchy. `shape="round"` makes it round.

## Toggle

With `toggle`, each click flips `pressed`: the button is announced as pressed or not, fills when active and bounces slightly. `onCrToggle` gives the new state.

## Badge and loading

`badge` shows a number or a short text, added to the accessible name: "Notifications (3)". The badge bounces when its value changes. `loading` replaces the icon with the indicator and blocks clicks.

## Tooltip

`tooltipPlacement` picks the side: `top` (default), `bottom`, `start` or `end`. Escape hides it; `tooltip={false}` removes it.

## Accessibility

- Native button named by `label`: the tooltip is a visual duplicate, ignored by screen readers.
- The tooltip opens immediately on keyboard focus and after 0.3 s on hover; it can be hovered without disappearing, and Escape closes it (WCAG criterion 1.4.13).
- No tooltip after a simple tap on a touch screen.
- Toggle state announced with `aria-pressed`; the active state changes the fill, not just the hue.
- Animations disabled with `prefers-reduced-motion`, and never on load.
- The icon is decorative: add `aria-hidden="true"` to it.
