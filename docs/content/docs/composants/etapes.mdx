## Exemple

Chaque étape est un `CrStep` avec un `label` ; seul le contenu de l'étape en cours est affiché. Avec `navigation`, les boutons « Précédent » et « Suivant » (« Terminer » à la dernière étape) sont ajoutés : le titre de l'étape arrive du côté où l'on avance et repart dans l'autre sens au retour. Par défaut (`variant="line"`), une bille lumineuse court sur la ligne et allume l'étape atteinte.

## Styles

La propriété `variant` change la façon de montrer la progression :

| Valeur | Effet |
|---|---|
| `line` | Bead Line : une bille lumineuse court sur la ligne et allume l'étape suivante (par défaut) |
| `number` | Big Number : un grand numéro bascule comme un panneau à volets, le nom de l'étape arrive en roulant |
| `path` | Skill Path : un chemin en zigzag ; l'étape en cours rebondit trois fois |
| `blocks` | Level Blocks : des blocs en escalier se remplissent l'un après l'autre, une bille saute sur l'étape en cours |
| `gauge` | Gauge Arc : une jauge en demi-cercle dont l'aiguille saute à la graduation suivante, comme un ressort |
| `timeline` | les étapes sont empilées verticalement, reliées par une ligne qui se remplit ; une étape validée se coche |

## Étapes verticales

Avec `variant="timeline"`, chaque étape affiche son titre et son contenu dans la ligne de progression. Placez vos propres boutons dans les étapes et appelez la méthode `next()` : l'étape se coche, la ligne se remplit, l'étape suivante s'ouvre et reçoit le focus. Après la dernière étape, `onCrComplete` est émis.

## Piloter les étapes

- `current` donne l'étape en cours (0 pour la première) ; elle vaut le nombre d'étapes quand tout est terminé.
- Les méthodes `next()`, `previous()` et `goTo(index)` changent d'étape, depuis une `ref` en React.
- `onCrStepChange` donne le nouvel index dans `event.detail` à chaque changement.

<Callout>
  Si l'utilisateur a demandé à son système de réduire les animations, la progression change sans aucun mouvement.
</Callout>

## Accessibilité

- La progression est un groupe nommé par `label` (« Progression » par défaut).
- Les lecteurs d'écran lisent la liste des étapes avec leur état (« terminée », « en cours », « à venir ») et l'étape en cours porte `aria-current="step"` ; les dessins (ligne, jauge, blocs…) leur sont masqués.
- Chaque changement d'étape est annoncé : « Étape 2 sur 4 : Profil », puis « Toutes les étapes sont terminées. ».
- Si le focus était dans une étape qui se masque, il passe sur la nouvelle étape ; si le bouton utilisé disparaît, il passe sur l'autre bouton.
- Le rebond de `path` s'arrête après trois fois : aucun mouvement sans fin.
