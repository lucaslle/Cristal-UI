## Example

Each step is a `CrStep` with a `label`; only the content of the current step is displayed. With `navigation`, "Previous" and "Next" buttons ("Finish" on the last step) are added: the step title comes in from the side you move towards and leaves the other way when going back. By default (`variant="line"`), a glowing bead runs along the line and lights up the step reached.

## Styles

The `variant` property changes how progress is shown:

| Value | Effect |
|---|---|
| `line` | Bead Line: a glowing bead runs along the line and lights up the next step (default) |
| `number` | Big Number: a large number flips like a split-flap display, the step name rolls in |
| `path` | Skill Path: a zigzag path; the current step bounces three times |
| `blocks` | Level Blocks: stair-step blocks fill up one after another, a bead jumps onto the current step |
| `gauge` | Gauge Arc: a half-circle gauge whose needle springs to the next mark |
| `timeline` | steps are stacked vertically, joined by a line that fills up; a completed step gets a check mark |

## Vertical steps

With `variant="timeline"`, each step displays its title and content inside the progress line. Put your own buttons in the steps and call the `next()` method: the step is checked, the line fills up, the next step opens and receives focus. After the last step, `onCrComplete` is emitted.

## Controlling the steps

- `current` gives the current step (0 for the first one); it equals the number of steps once everything is completed.
- The `next()`, `previous()` and `goTo(index)` methods change the step, from a `ref` in React.
- `onCrStepChange` gives the new index in `event.detail` on every change.

<Callout>
  If the user has asked their system to reduce motion, progress changes without any movement.
</Callout>

## Accessibility

- The progress indicator is a group named by `label` ("Progress" by default, "Progression" in French).
- Screen readers read the list of steps with their state ("completed", "current", "upcoming") and the current step has `aria-current="step"`; the drawings (line, gauge, blocks…) are hidden from them.
- Each step change is announced: "Step 2 of 4: Profile", then "All steps are completed.".
- If focus was in a step that gets hidden, it moves to the new step; if the button used disappears, it moves to the other button.
- The `path` bounce stops after three times: no endless motion.
