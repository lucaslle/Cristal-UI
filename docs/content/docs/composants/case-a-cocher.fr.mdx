## Dans un formulaire

Une case cochée envoie sa `value` (`on` par défaut) sous son `name` ; une case décochée n'envoie rien, comme une case native. Voir l'exemple complet sur la page [Champ texte](/docs/composants/champ-texte#dans-un-formulaire).

`error-animation` anime l'erreur quand elle apparaît et à chaque envoi refusé (zigzag, pastille, écho…) : voir [Erreur animée](/docs/composants/champ-texte#erreur-animée).

## Accessibilité

- Case native sous le capot : se coche avec Espace, annoncée « case à cocher, cochée / non cochée ».
- Le libellé est cliquable et agrandit la zone de clic.
- `indeterminate` est annoncé « partiellement coché ».
