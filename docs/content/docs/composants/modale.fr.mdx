## Accessibilité

Cristal utilise l'élément natif `<dialog>` ouvert en mode modal :

- le **focus** entre dans la fenêtre à l'ouverture, **reste piégé** à l'intérieur, et **revient** au bouton d'ouverture à la fermeture ;
- **Échap** ferme la fenêtre ; un clic sur le fond assombri, à côté, la ferme aussi ; `closeOnBackdrop={false}` l'empêche, par exemple pour un long formulaire qu'un clic malheureux ferait perdre ;
- le reste de la page devient **inerte** (ni cliquable, ni lisible par les lecteurs d'écran) et ne défile plus ;
- le titre (`label`) sert de nom à la fenêtre ; le bouton de fermeture est étiqueté « Close », ou « Fermer » sur une page en français (modifiable avec `closeLabel`).
