## Example

`CrBox` replaces a `div`: spacing, flex and grid are set with properties, and children stay direct children, so flex and grid apply to them properly.

## Values

| Property | Values |
|---|---|
| `display` | `block` (default), `flex`, `grid`, `inline-flex`, `inline-block`, `none` |
| `direction` | `row`, `column` (and their reverses) |
| `gap`, `padding` | `xs` 4px, `sm` 8px, `lg` 16px, `xl` 24px, `2xl` 32px, `3xl` 48px, or any CSS value; `padding="sm xl"` gives vertical then horizontal |
| `align`, `justify` | like `align-items` and `justify-content`: `center`, `space-between`… |
| `wrap` | wraps to the next line when space runs out |
| `columns` | grid: `3` equal columns, or `220px` for as many columns of at least 220px as space allows |
| `background` | `surface`, `muted`, `subtle`, `primary` (with matching text), or any CSS color |
| `radius` | `m`, `l`, `full`, or any CSS value |
| `border`, `shadow` | thin border, soft shadow |
| `maxWidth` | maximum width, centered |

<Callout>
  `CrBox` has no role: like a `div`, it tells screen readers nothing. For an area with meaning (navigation, list, article), keep the appropriate HTML element.
</Callout>
