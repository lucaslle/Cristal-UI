## Just one color to choose

To give the whole application your color, one line is enough, after importing `@cristal/react/tokens.css`:

```css title="theme.css"
:root {
  --cr-color-primary: #e11d48;
}
```

All the other shades are **computed automatically** from that color:

- the hover shade (darker for a dark color, lighter for a light color);
- the light background of secondary buttons and hovered options;
- a version dark enough to be read as text, outline or focus indicator on a white background;
- the color of text placed on the primary color: white on a dark color, black on a light color.

## A theme for part of the page

Add the `cr-theme` class to a container and redefine the color on that container: only the components inside it change.

```tsx
<section className="cr-theme" style={{ '--cr-color-primary': '#0f766e' }}>
  <CrButton>Teal button</CrButton>
</section>
```

<Callout type="warn">
  The builder checks the contrasts of your color. Mid-range colors (neither really light nor really dark) can stay below the 4.5:1 threshold: the builder then says so.
</Callout>

## Dark theme

The dark theme is **opt-in**: import its stylesheet after the tokens, then set `data-theme="dark"` on `<html>`. Without that attribute nothing changes, even when the user's system is in dark mode: you decide when to turn it on.

```tsx title="app/layout.tsx"
import '@cristal/react/tokens.css';
import '@cristal/react/tokens-dark.css';

<html lang="en" data-theme="dark">
```

- Surface, text, borders, disabled states, danger, success, overlay and shadow take dark values, and `color-scheme: dark` adapts native controls and scrollbars.
- **Your primary color does not change**: filled buttons keep your brand. Its derived shades adapt: text, focus outline and indicators (stars, slider, switch, checked box) switch to a light shade of your color, and the background of secondary buttons mixes with the dark surface instead of white.
- Contrasts stay those of the light theme: at least 4.5:1 for text, 3:1 for borders, focus and indicators.

For a single area, the `cr-theme-dark` class applies the dark theme to a container; `cr-theme` brings back the light theme there. In a dark page, give your local color with `cr-theme-dark`:

```tsx
<section className="cr-theme-dark" style={{ '--cr-color-primary': '#0f766e' }}>
  <CrButton>Teal button, dark version</CrButton>
</section>
```

### CSS parts

For finer control, each component exposes **parts** that can be styled from outside with `::part()`. They are listed at the bottom of each component page.

```css
cr-input.search::part(label) {
  color: white;
}
```
